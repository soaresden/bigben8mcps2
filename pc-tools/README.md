# PC tools

| Tool | Purpose |
|---|---|
| `datel_xmem_extract.py` | Recover the saves Datel's MegaMem software hid (compressed, "deleted") on a card, from a dump made with `MMDUMP.ELF` (or any 8 MB image with or without ECC). Writes `.psu` files. Pure Python 3. |
